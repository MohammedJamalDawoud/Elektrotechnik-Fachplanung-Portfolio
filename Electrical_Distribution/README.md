Dieser Ordner enthält bestätigte Zertifikate zur Planung elektrischer Verteilersysteme sowie zur Anwendung einschlägiger Software.

  *Zertifikat für elektrische Energieverteilung*

-  **Electrical Design – Course Certificate**
